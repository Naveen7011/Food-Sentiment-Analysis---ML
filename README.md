🍔 Food Sentiment Analysis

This project is a Machine Learning based NLP application that analyzes food reviews and predicts whether the sentiment is Positive 👍 or Negative 👎.

Features

💠 Predict sentiment from food reviews
💠 Single Review Prediction
💠 Bulk Review Prediction using CSV
💠 Built with Python, Scikit-learn, and Streamlit

Technologies Used

Python • Pandas • NumPy • Scikit-learn • NLP • Streamlit
